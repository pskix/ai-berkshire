# 实盘运转手册 — 华泰新户(A股)× ai-berkshire

> 制定日期:2026-08-10。定义"筛选 → 深研 → 建仓决策 → 执行 → 跟踪"的完整闭环。
> 与 `docs/ROADMAP.md`(项目功能开发路线)相互独立。
>
> **本账户的起点**:华泰证券账户为**新开户、空仓**,主要面向 A 股。
> 既有的港股/美股持仓(见 `实盘记录/实盘操作记录.md`)在其他渠道,
> 因此本手册从**筛选标的**开始,而不是从导入持仓开始。

## 总体定位

**本 repo = 投研决策支持系统,华泰专业版Ⅲ = 执行终端,本人 = 唯一决策者。**

- 不做自动下单。低频价值投资下人工执行成本极低,而自动化会带来错单风险与
  程序化交易报备义务(《证券市场程序化交易管理规定(试行)》"先报告、后交易")。
- AI 只用在**只读侧**:筛选、研究、读持仓截图、整理数据。下单动作永远人工完成。
- 每个买入决策必须先有报告,给出**买入价格区间 + 仓位 + 卖出条件**三要素,缺一不执行。
- 本 repo 产出的是研究材料,不是投资建议;所有决策与后果由本人承担。

> **空仓期的最大优势:没有沉没成本。** 新户阶段可以只研究、不交易,
> 把候选池和研究底稿攒厚,等真正"一眼胖瘦"的机会出现再动手。急于建仓是最贵的错误。

## 阶段 0:确认可交易范围(第一步,决定筛选池边界)

新开户默认只能交易**沪深主板**。以下板块需额外权限,在华泰 APP/专业版内确认并开通:

| 板块 | 常见门槛(需以华泰实际要求为准) |
|---|---|
| 创业板 | 前 20 交易日日均资产 10 万 + 24 个月证券交易经验 |
| 科创板 | 前 20 交易日日均资产 50 万 + 24 个月证券交易经验 |
| 北交所 | 前 20 交易日日均资产 50 万 + 24 个月证券交易经验 |
| 港股通 | 前 20 交易日日均资产 50 万 |

> "24 个月交易经验"从**首次证券交易**起算(任一券商均可累计),境外券商的港美股交易一般不计入。
> 门槛细则各券商执行口径可能不同,**开通前先在华泰确认**。

**为什么这一步在最前面**:如果只能交易主板,那么把精力花在科创板/港股通标的上是浪费。
筛选池必须先对齐"实际能买什么"。同时注意:若日后开通港股通,
需与既有港股持仓合并看权重,避免同一标的跨账户重复暴露。

- `筛选公司/科创板股召回池/` — 科创板 100 去劣筛选 + 通过公司排序(**开通科创板后才有用**)
- `reports/召回池`、`reports/晨星估值筛选` 等已有筛选成果

新增召回的两个入口:

| 想法来源 | 命令 | 产出 |
|---|---|---|
| 有明确行业方向("AI 算力""创新药") | `/industry-funnel {行业}` | 全市场逐层精选到 3 家,每层留弃标准可追溯 |
| 想先看清产业链再选股 | `/industry-research {行业}` → 再跑 funnel | 产业链全景 + 环节切片 |

> 召回阶段的原则:**宁可多召,不可漏召**。过滤是下一阶段的事。

## 阶段 2:去劣筛选(候选池 → shortlist)

`/quality-screen {公司列表 | 行业 | 指数}` — 7 条去劣指标,目标是
**不错杀一流公司,但能排除确定的非一流公司**。支持个股/行业/市场/主题四种输入。

输出落到 `筛选公司/` 下,保留通过与未通过两份名单(未通过的理由日后要能复查)。
shortlist 控制在 **3–5 家**,再多就深研不动了。

## 阶段 3:深度研究(shortlist → 可投清单)

| 深度 | 命令 | 何时用 |
|---|---|---|
| 完整四大师并行研究 | `/investment-team {公司}` | 认真考虑建仓的标的,产出目录级报告 |
| 单人版综合研究 | `/investment-research {公司}` | 快一档,先判断值不值得上 team |
| 买入前最后核对 | `/investment-checklist {公司}` | 巴菲特买入前 Checklist |
| 管理层专项 | `/management-deep-dive {公司}` | 管理层是关键变量时 |

研究纪律(CLAUDE.md 已定):客观、事实与观点分离、不预设立场、呈现正反两面、
数据双源交叉验证、市值手算校验(`tools/financial_rigor.py`)、报告数字审计(`tools/report_audit.py`)。

**镜子测试**:决定建仓前,按 `实盘记录/` 里已有的镜子测试模板
(`PDD_镜子测试_20260421.md`、`MiniMax_镜子测试_20260727.md`)写一份——
用自己的话讲清楚"为什么买、错在哪会亏、什么情况下认错"。写不出来就是没想清楚,不买。

## 阶段 4:建仓决策(动手前的最后一关)

1. **估值锚点与买入区间**:来自深研报告,不锚定成本价,只锚定内在价值口径。
2. **仓位**:`/portfolio-review` 在空仓期的用法是**规划目标组合结构**
   (行业/地域集中度、与既有港美股持仓的相关性、机会成本排序),而不是诊断现有持仓。
   注意组合是**跨账户合并**看的,华泰 A 股仓位要和既有港美股一起算权重。
3. **先写卖出条件,再买**:在 `实盘记录/卖出条件.md` 中为新标的补一条,
   包含"估值离谱线 / 证伪即卖 / 触发重审"三类条款。
   框架依据(李录):卖出的合法理由只有三个——看错了、论文被证伪、有明显更好的机会;
   涨跌幅、成本价、宏观情绪都不是理由。
4. **新户建议先试探仓**:repo 既有先例(PDD、MiniMax 均以试探仓起步)。
   新账户还要顺带验证交易通道本身(委托、成交、交割是否符合预期)。

## 阶段 5:执行与记录

1. 人工在华泰专业版Ⅲ下单。
2. **当天**记入 `实盘记录/实盘操作记录.md`:日期、标的、操作、价格、仓位变化、
   **依据哪份报告**(链接)。沿用既有口径:**公开决策与权重,不公开股数与金额**(段永平做法)。
3. 建仓后立即建立投资论文:`/thesis-tracker {公司名}` → `reports/{公司}/{公司}-thesis.md`。

## 阶段 6:持有期跟踪(买入之后才是真正的工作)

| 触发条件 | 动作 | 含义 |
|---|---|---|
| 单日 ±5% / 一周 ±10% | `/news-pulse {公司}` | 10 分钟归因:噪音(不动)or 信号(触发论文重审) |
| 季报/年报 | `/earnings-review` 或 `/earnings-team` → `/thesis-tracker {公司} 季度检查` | 论文成立→持有;受损→对照卖出条件 |
| 季度例行 | `/thesis-drift` | 全持仓论点漂移检查 |
| 组合层面 | `/portfolio-review 我的持仓` | 权重、相关性、机会成本重排 |

**持仓同步**:华泰专业版Ⅲ 的持仓可截图交给 Claude 读取整理,
或导出后维护到 `reports/portfolio-latest.md`(跨账户合并口径)。

> ⚠️ **隐私**:本 repo 推送到公开 GitHub。持仓一律用**百分比权重**记录,
> 不写股数与金额;账户号、资金余额等绝不入库。

## 阶段 7(可选,数月后再评估):半自动化

仅当发现自己在重复执行机械规则(分批建仓、条件触发)时才考虑:

1. 先用 SuperMind 网页版(同花顺,免费)回测验证规则;
2. 再评估华泰 Ptrade/QMT(约 50 万资产门槛),需签程序化交易补充协议并完成交易所报备;
3. 在此之前,这一步是负收益的复杂度,不做。

## 最小启动动作(按顺序)

1. **今天**:在华泰确认可交易板块(主板/创业板/科创板/港股通)→ 定下筛选池边界。
2. **本周**:选 1 个自己看得懂的方向,跑 `/industry-funnel` 或直接复用
   `筛选公司/A股召回池/` 的行业分册 → `/quality-screen` 得到 3–5 家 shortlist。
3. **两周内**:对 shortlist 里最看得懂的 1–2 家跑 `/investment-team` 深研 + 镜子测试。
4. **有结论后**:先写卖出条件 → 再谈建仓;没有"一眼胖瘦"就继续空仓等待。
