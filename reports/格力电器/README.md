# 格力电器（000651.SZ）投研团队研究

> 研究日期：2026-08-10｜现价 ¥40.67｜四大师并行研究框架
> 数据基准：巨潮资讯网 2021–2025 年报及 2026 一季报原文 PDF + 东方财富交叉验证
> 数据抽检：**【准出】** 3/3 通过（`tools/report_audit.py`，15% 随机抽样）

## 一句话结论

盈利能力极强（净利率 16.93%，为美的 1.7 倍、海尔 2.5 倍）但正在丢失份额（2023→2025 营收 -16.5%）的好生意；
市场折价的对象是**净资产**而非盈利（PB 处 8.6 年第 5.9 分位 vs PE 处 5 年第 51 分位），
核心矛盾因此是**治理与资本配置**，不是经营——约 1,745–2,599 亿低效类现金能否释放，决定这是价值修复还是价值沉淀。

**综合评分：★★☆（约 2.4 / 5）**｜巴菲特 Checklist：通过 3 / 观察 4 / 不通过 3

## 最快的验证窗口

**50–100 亿回购是否实际执行**（2026-04-28 董事会、06-30 股东会通过，价格上限 56.55 元，≥70% 用于注销；
截至 2026-07-31 **零执行**，账上现金 1,459 亿）。每月初有进展公告——这是检验管理层股东回报诚意最直接的观察点。

**次要裁决点**：2026 中报（8 月底前披露）。2024–2025 数据支持"格力掉队"，2026Q1 数据支持"格力最抗跌"，中报将裁决。

## 研究局限（诚实声明）

格力自 2024 年底起不再单独披露空调收入（合并为"消费电器"），且财报含未披露金额的甲供贸易收入。
**-16.5% 的营收下滑中，多少是低毛利贸易主动收缩、多少是空调主业真实失血，公开数据无法拆解。**
