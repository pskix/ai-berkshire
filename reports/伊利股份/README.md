## 一句话结论

伊利是**一位卓越的运营者与平庸的买家**，在一个已确定见顶的行业里持续赢得份额；
但当前利润来自**奶价历史低位的周期红利而非成长**（四视角独立验证，可比口径实际增速仅 +0.23%），
且**资本开支已低于折旧（0.75x）**。市场按"票息 5.26%、增长 3% 的准债券"定价——
DDM 得 25.84 元几乎等于现价 26.26 元，**定价理性，不是错杀**。

**综合评分：★★★（3.0 / 5）**｜巴菲特 Checklist：通过 4 / 观察 4 / 不通过 2

## 本次研究最有价值的结论

**四个视角用完全不同路径，独立否定了"2025 净利 +36.82% 创历史最好"这一叙事：**

| 视角 | 独立证据 |
|---|---|
| 段永平 | 剔除 2024 澳优减值 30.4 亿后，可比增速仅 **+0.23%** |
| 芒格 | 营收仅 +0.13%，利润来自奶价历史最低（3.06 元/kg，-8.0%）→ **周期底部利润** |
| 巴菲特 | 2026Q1 扣非>归母 **纯属非经常性基数收缩**（2.45→0.66 亿），非经营加速 |
| 李录 | 净利 +36.8% 同时经营现金流 **-34.02%**，成因为预收经销商货款下滑 |

## 最大未决问题（本次研究核心验证点）

**2026Q1 液体乳"率先转正"(+2.32%) 是真复苏还是渠道压货？**

- 支持压货：合同负债 **-6.49%**（已连续两期下滑）、应收账款 +14.16%、2025 年 OCF -34.02%
- 支持复苏：2026Q1 经营现金流 +293.92%

→ **以 2026 中报（8 月底前披露）的"合同负债 + 应收周转天数 + 经销商数量"三项交叉验证。**
